# Rutina

App personal de Rodri: horario del día con avisos, misiones diarias con XP y rangos, metas y progreso.

- `src/rutina.html`: la app (la misma página del Artifact de Claude).
- `www/horario.json`: el horario. La app lo descarga al abrirse y reprograma los avisos cuando cambia `version`. Editar este archivo no recompila la app.
- Descargar la app: https://github.com/Jhoel-ui/rutina/releases/latest/download/rutina.apk
